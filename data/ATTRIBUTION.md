# Data attribution

`raw/sim_issues_2026-09-25.json` is a snapshot of the public GitHub issues of
https://github.com/simstudioai/sim, taken with `scripts/fetch_issues.sh` on
2026-09-25. `issues.jsonl` holds the 100 issues drawn from it by
`scripts/sample_issues.py`. Each record links to its original issue.

Sim's code is Apache-2.0. The issue text belongs to the people who wrote it and
is reproduced here only as evaluation input, unmodified apart from the
truncation documented in the sampler. If you wrote one of these issues and
want it removed, open an issue on this repo and it will be dropped and the
results regenerated.
